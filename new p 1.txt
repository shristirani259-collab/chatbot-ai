1. Project Overview

This project is a simple Rule-Based AI Chatbot developed using Python.

The chatbot responds to predefined user inputs using if-else decision-making logic. It continuously accepts messages from the user until an exit command is entered.

This project focuses on fundamental Artificial Intelligence concepts such as control flow, decision-making, and basic human-computer interaction.

2. Objective

The main objective of this project is to create a chatbot that:

- Handles greetings.
- Responds to predefined questions.
- Handles exit commands.
- Uses "if-elif-else" logic.
- Runs continuously using a loop.
- Demonstrates basic rule-based AI concepts.

3. Technologies Used

- Python 3.x
- Conditional statements ("if", "elif", "else")
- "while" loop
- String methods
- Command-line interface

5. How It Works

The chatbot takes input from the user and converts it to lowercase.

It then checks the input against predefined rules.

For example:

User: hello
Bot: Hello! How can I help you?

If the user enters an exit command such as "bye", "exit", or "quit", the chatbot ends the program.

For an unknown input, the chatbot provides a default response.

7. Installation

Step 1: Install Python

Install Python 3.x on your computer.

Step 2: Download or clone the project

Place "main.py" in your project folder.

Step 3: Run the program

Open Command Prompt or Terminal inside the project folder and run:

python main.py

If your system uses "python3", run:

python3 main.py

8. Key Concepts Demonstrated

Control Flow

The program uses conditional statements to determine the appropriate response.

Decision-Making Logic

Different user inputs trigger different predefined responses.

Continuous Loop

A "while" loop allows the chatbot to continue interacting with the user until an exit command is entered.

Rule-Based AI

The chatbot does not learn from data. Instead, it follows explicitly programmed rules to generate responses.
